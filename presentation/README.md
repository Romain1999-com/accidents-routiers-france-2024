# Soutenance (10–15 minutes)

Le support `Soutenance_Accidents_Routiers_2024.pptx` présente l'objectif, la chaîne technique, le modèle, le diagnostic GPS, les six dashboards et les limites.

Conseil : viser environ 1 minute par diapositive, consacrer 2 minutes à une démonstration interactive dans Tableau Desktop, et conserver les captures en solution de secours. Vérifier la connexion MySQL avant de commencer.
